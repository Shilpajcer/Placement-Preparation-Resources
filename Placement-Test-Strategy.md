# 🎯 Placement Test Strategy

A practical guide for students preparing for online placement tests, coding assessments, and campus recruitment tests.

---

## 1. 📝 Understand the Test

Before starting preparation, check the company's:

- Eligibility criteria
- Test pattern
- Number of sections
- Number of questions
- Time limit
- Negative marking
- Coding questions
- Allowed programming languages

> **Always prepare according to the company's actual test pattern when it is available.**

# 3. ⏱️ Time Management

Time management is one of the most important skills during an online assessment.

### Simple Strategy

1. Read the question carefully.
2. Identify the easiest questions.
3. Solve easy questions first.
4. Do not spend too much time on one question.
5. Keep time for difficult questions at the end.
6. Review answers if time is available.

### Example

If you have **30 questions in 30 minutes**:

Aim to solve the easier questions quickly instead of spending 5 minutes on one difficult question.

> **Don't let one question consume your entire test.**

# 4. 🧮 Aptitude Strategy

### Before the Test

Revise:

- Percentages
- Profit & Loss
- Ratio
- Average
- Time & Work
- Time, Speed & Distance
- Simple Interest
- Probability
- Number System
- HCF & LCM
- Basic reasoning

### During the Test

For each question:

**Read → Identify formula → Calculate → Check → Move on**

If a question requires too much calculation, mark it and return later if the test allows it.

# 5. 💻 Coding Test Strategy

Before writing code:

### Step 1 — Understand the Problem

Identify:

- Input
- Output
- Constraints
- Examples
- Edge cases

### Step 2 — Think of the Approach

Ask yourself:

- Can I use an array?
- Can I use a string?
- Do I need a loop?
- Do I need a dictionary/set?
- Is sorting useful?
- Can I solve it using two pointers?
- Is there a simpler approach?

### Step 3 — Write the Code

Start with the simplest correct solution.

### Step 4 — Test

Test:

- Normal case
- Minimum input
- Maximum input
- Duplicate values
- Empty/special cases where applicable

---

# 6. 🧠 What If You Get Stuck?

Don't panic.

Use this approach:

### First 2–3 minutes

Understand the problem properly.

### Next

Try a small example manually.

### Then

Think of a simple brute-force approach.

### If still stuck

Move to another question if the test allows it.

> **A difficult question is not worth losing several easy questions.**

---

# 7. ❌ Common Placement Test Mistakes

Avoid:

- ❌ Starting with the hardest question
- ❌ Spending too long on one question
- ❌ Ignoring the question constraints
- ❌ Not checking sample inputs
- ❌ Submitting code without testing
- ❌ Using a programming language you are not comfortable with
- ❌ Guessing without considering negative marking
- ❌ Panicking when one question looks unfamiliar

---

# 8. 🧪 Coding Test Checklist

Before submitting code, check:

- [ ] Does the code compile?
- [ ] Is the input handled correctly?
- [ ] Is the output format correct?
- [ ] Did I test the sample input?
- [ ] Did I test edge cases?
- [ ] Is the time complexity reasonable?
- [ ] Is the code free from unnecessary print statements?

# 10. 📊 Mock Test Strategy

Don't just take mock tests.

After every mock test:

### Step 1

Record your score.

### Step 2

Identify incorrect questions.

### Step 3

Find the reason for each mistake.

Examples:

- Concept not known
- Calculation mistake
- Misread question
- Time pressure
- Coding error

### Step 4

Revise that topic.

### Step 5

Try a similar question again.

> **A mock test is useful only when you learn from your mistakes.**

# 12. 🎯 Company-Specific Preparation

Once you know the company, don't prepare randomly.

Research:

- Previous test pattern
- Aptitude topics
- Coding difficulty
- Number of coding questions
- Technical interview topics
- Frequently asked questions

Then adjust your preparation accordingly.

### Preparation Formula

**Company Pattern → Important Topics → Practice → Mock Test → Analyze Mistakes**

---

# 13. 🧑‍💻 During the Actual Test

Before starting:

- Keep your internet connection stable.
- Charge your laptop.
- Keep required documents ready.
- Check the test instructions.
- Close unnecessary applications.
- Keep water nearby.
- Stay calm.

During the test:

**Read carefully → Solve confidently → Manage time → Review**

---

# 14. 🚨 If the Test Goes Badly

One bad test does not define your placement preparation.

After the test:

1. Don't panic.
2. Identify what went wrong.
3. Write down the difficult topics.
4. Revise them.
5. Practice similar questions.
6. Prepare better for the next opportunity.

> **Every test gives you information about what to improve.**
